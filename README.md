Entry for make.fun bounty **news-image-20261124** — "Sum up 24 November's
world news in one image" ($100 USDC, 50 places paid).

## Image

1024×1024 front page, Tuesday 24 November 2026, 44 stories. 3 AI lead
photos, 12 AI illustrations, stats row, region bar, UTC timeline, real
world map with pins, DATE CHECK box. Every event happened or was first
reported 24 Nov 2026; 20–23 Nov events appear only in the DATE CHECK box.

## Run

`main.py` (Python 3.13, stdlib only) copies `entry.png` to
`$MAKEFUN_OUTPUT_DIR` (default `/output`). `gen_image.py` regenerates
`entry.png` deterministically from `build/` assets.
